# Output Specifications & Submission Package

## 1. Required Output Files
The pipeline must write two TSV files into `output/` with single tab separators:

### A. `output/matching_results.tsv` (Leaderboard Scored)
Final high-precision entity matches.
- **Columns:** `source1_entity_id\tmatched_entity_ids`
- **Format:** Comma-separated target IDs with no surrounding spaces or quotes (e.g., `S2-00047,S3-00812`).
- **Singletons:** Keep `matched_entity_ids` completely empty (`S1-00003\t`).
- **Integrity:** Exactly one row per test `source1_entity_id`. No duplicate IDs in the comma-separated list.

### B. `output/candidate_pairs.tsv` (Blocking Audit)
The exact candidate set generated by Stage 1 blocking before model scoring.
- **Columns:** `source1_entity_id\tcandidate_entity_ids`
- **Integrity:** Exactly one row per test `source1_entity_id`. All items from `matching_results.tsv` must exist in this candidate list.

    ## Final Submission Package Specification

At the end of development, the final deliverable must be packaged into `<team_name>_submission.zip` with this exact internal hierarchy:

<team_name>_submission.zip
├── output/
│   ├── matching_results.tsv        # Evaluated on the leaderboard
│   └── candidate_pairs.tsv         # Candidate set before final scoring
├── code/
│   └── business_entity_resolution/
│       ├── src/                    # Modular source files (blocking, matching, pipeline)
│       ├── README.md               # Exact commands to run from dataset -> output
│       └── requirements.txt        # Pinned dependencies
└── Documentation_template.md       # Filled-in methodology write-up

### Code Packaging Rules:
- All paths referenced in `code/business_entity_resolution/` must be relative to the repository root.
- Anyone running `python code/business_entity_resolution/src/run_pipeline.py` must be able to reproduce both TSV files in `output/` using only the local data and models.
- Run `python3 utils/validate_submission.py --matching output/matching_results.tsv --candidate output/candidate_pairs.tsv --test-dir dataset/test` prior to archiving.
